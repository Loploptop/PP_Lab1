Заданный численный метод: Метод Трапеций для приближенного значения определенного интеграла

Реализовать заданный метод численного интегрирования на языке С++ двумя способами:
1)с использованием стандарта POSIX (функций pthread_create, pthread_join);
2)средствами std::thread.
Входные параметры: пределы интегрирования, количество потоков (от 1 до 8), величина шага или количество шагов.
Выходная информация: значение интеграла, время затраченное на вычисления.
Подынтегральная функция выбирается самостоятельно.

В программе с использованием стандарта POSIX использовать механизм получения возвращенного значения через pthread_join.
В программе с использованием std::thread параметры функции выполняемой в потоке передавать по отдельности (не объединяя в структуру).
